# deepseek-rtl

Userscript that fixes RTL text alignment, emoji positioning, and font
consistency for Persian, Arabic, Urdu, Pashto, Kurdish, and Hebrew on
[DeepSeek](https://chat.deepseek.com). Code blocks, inline code, and syntax
highlighting always stay LTR.

## Install

Install the script from GreasyFork or load `deepseek-rtl.user.js` directly in
your userscript manager.

A floating **RTL ON / RTL OFF** button (bottom-right) toggles the behavior and
remembers your choice in `localStorage`.

## Versioning

`deepseek-rtl.user.js` is the installable script. `deepseek-rtl.meta.js` is the
metadata-only file referenced by `@updateURL`.
